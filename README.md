# UniversalAgent (ЦУА) — Универсальный Целостный Агент

![CI](https://github.com/rtynbirf/universal-agent/actions/workflows/ci.yml/badge.svg)
![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Tests](https://img.shields.io/badge/tests-36%2F36-brightgreen)

Не система склеенных частей, а **одна сущность**: один мозг, четыре контура памяти,
руки-инструменты, внутренний цикл воли и автономный демон. Только стандартная
библиотека Python 3.10+ — ноль внешних зависимостей.

```
┌──────────────────────────────────────────────────────────────┐
│  СЛОЙ 4 · ВОЛЯ          run_daemon(): очередь задач → solve() │
├──────────────────────────────────────────────────────────────┤
│  СЛОЙ 3 · ПАМЯТЬ        рабочая | эпизодическая | семантическая│
│                         | процедурная (SQLite + FTS5)         │
├──────────────────────────────────────────────────────────────┤
│  СЛОЙ 2 · РУКИ          реестр @tool: read/write/list/exec/   │
│                         web_search/remember/recall            │
├──────────────────────────────────────────────────────────────┤
│  СЛОЙ 1 · ЦИКЛ          solve(): АНАЛИЗ→ПЛАН→ДЕЙСТВИЕ→РЕФЛ.   │
│                         JSON-протокол, бюджет шагов, ремонт   │
├──────────────────────────────────────────────────────────────┤
│  СЛОЙ 0 · МОЗГ          LLMCore (модель-агностик, OpenAI API) │
└──────────────────────────────────────────────────────────────┘
```

## Быстрый старт

```bash
# 1. Ядро — любой OpenAI-совместимый рантайм
export UA_LLM_BASE_URL="http://localhost:11434/v1"   # Ollama
export UA_LLM_MODEL="qwen3:30b-a3b"

# 2. Разовая задача
python universal_agent.py task --task "Изучи каталог workspace и напиши инвентаризацию"

# 3. Автономная жизнь (демон воли)
python universal_agent.py daemon &
echo "Найди в workspace все TODO и сведи в список" >> task_queue.txt
```

Поддержанные рантаймы (диалект один и тот же):

| Рантайм | UA_LLM_BASE_URL |
|---|---|
| Ollama | `http://localhost:11434/v1` |
| vLLM | `http://localhost:8000/v1` |
| LM Studio | `http://localhost:1234/v1` |
| Облако | URL провайдера + `UA_LLM_API_KEY` |

Смена мозга — две переменные окружения. Тело агента не меняется.

## Установка

```bash
# из исходников (ноль зависимостей)
pip install -e .
universal-agent task --task "текст задачи"   # точка входа из pyproject

# или Docker (изолированный non-root рантайм)
docker build -t universal-agent .
docker run --rm universal-agent task --task "текст задачи"
```

Инструменты разработчика:

| Команда | Действие |
|---|---|
| `make verify` | канон: check.py (компиляция + тесты + гигиена + манифест) |
| `make test` | unittest-набор подробно |
| `make lint` | ruff check |
| `make manifest` | пересборка release/manifest_sha256.txt |
| `make run TASK="..."` | разовая задача |
| `make daemon` | автономная жизнь |

## Протокол мышления

Каждый ход агента — строго JSON (ReAct-дисциплина):

```json
{"thought": "краткая мысль шага",
 "action": {"name": "execute_python", "params": {"code": "print(2+2)"}}}
```

Завершение — инструмент `finish` с финальным отчётом. Нарушение формата не
валит цикл: парсер ремонтирует ограждения/обвязку, при полном провале агент
получает «НАРУШЕНИЕ ПРОТОКОЛА» и повторяет ход. Ошибка любого инструмента —
**наблюдение**, а не крах: мозг видит текст ошибки и корректирует план.

## Память: четыре контура

| Контур | Реализация |
|---|---|
| Рабочая | история сообщений с усечением наблюдений |
| Эпизодическая | таблица `events` (задачи, действия, наблюдения, отчёты) |
| Семантическая | FTS5-индекс (фолбэк — LIKE-режим) + `knowledge/*.md` |
| Процедурная | дистилляция уроков после каждой задачи |

Выборка — гибридный скоринг (Park et al., 2023 / кривая Эббингауза):

```
score = (1/(1+позиция_BM25)) × ( exp(−возраст/полураспад) + значимость )
```

Ничего не удаляется никогда — меняется лишь вес доходимости. После завершения
задачи мозг отвечает себе, пригодится ли техника другим задачам; если да —
карточка урока пишется в `knowledge/` и индексируется с значимостью 0.95.

## Песочница исполнения

`execute_python` ограничен: RLIMIT_CPU, RLIMIT_AS, потолок времени,
убийство всей группы процессов по таймауту, cwd = workspace, отсечение
параметров вне схемы. Опционально `UA_EXEC_NET_ISOLATE=true` добавляет
`unshare -n` (сетевая изоляция, нужны user namespaces).

**Контейнерная песочница (фаза II, «Крепость»):** `UA_EXEC_DOCKER=1`
поднимает границу на уровне ядра — каждый вызов исполняется в отдельном
контейнере с `--network none` (сеть отрезана), cgroup-лимитами
(`UA_EXEC_MEM_MB` → `--memory`, `UA_EXEC_DOCKER_CPUS` → `--cpus`,
`UA_EXEC_DOCKER_PIDS` → `--pids-limit`, swap-побег закрыт),
`--read-only` корнем ФС, сбросом capabilities (`--cap-drop ALL`),
запретом повышения привилегий и не-root пользователем; workspace
монтируется внутрь, по таймауту контейнер снимается `docker kill`.
Образ задаётся `UA_EXEC_DOCKER_IMAGE` (по умолчанию `python:3.12-alpine`).
Если docker недоступен — автоматический откат на локальные RLIMIT-лимиты
с пометкой в наблюдении; агент не останавливается.

**Честное предупреждение:** RLIMIT-песочница — не жёсткая граница безопасности.
Для враждебного ввода включайте `UA_EXEC_DOCKER=1`; ещё жёстче — gVisor/nsjail
поверх данного каркаса.

## Тесты (без сети, на mock-мозге)

```bash
python -m unittest discover -s tests -v
```

Покрыто: экстрактор JSON и приведение типов; память (BM25-ранжирование,
новизна, значимость, LIKE-фолбэк); границы workspace и дисциплина dispatch;
файловые руки и песочница (stdout/exit, syntax error, TIMEOUT, RLIMIT_AS);
контейнерная песочница на фейковом docker CLI (жёсткость флагов, видимость
workspace, снятие по таймауту, откат при недоступном docker, конфиг из env);
три сквозных сценария (полный цикл с консолидацией урока, ремонт протокола,
честный частичный итог при исчерпании бюджета).

## Релизная инженерия (канон POLIMAT)

- `scripts/check.py` — верификатор канона: компиляция, тесты, скан секретов,
  сходимость `release/manifest_sha256.txt`, комплектность. Строка `# Result:` — пропуск на пуш.
- Conventional Commits + DCO (`git commit -s`), PR = 24ч → squash (см. CONTRIBUTING.md).
- `make manifest` — SHA-256-манифест ключевых файлов релиза.

## Дорожная карта

- **Фаза I — Жизнь:** подключить реальный рантайм, 10 бытовых задач, ≥8/10 до finish.
- **Фаза II — Крепость:** ✅ docker-песочница (`UA_EXEC_DOCKER=1`); далее — failover-ядро,
  полноценный поисковый API.
- **Фаза III — Глубина памяти:** эмбеддинги + sqlite-vec поверх FTS5, ночная
  консолидация (схлопывание дублирующихся уроков).
- **Фаза IV — Метапознание:** телеметрия сбоев, самоограничения в
  `knowledge/constraints.md`, интерфейсы воли (Telegram/CLI/Web).

## Публикация в git

```bash
git init && git add . && git commit -m "ЦУА v2.1"
git remote add origin git@github.com:you/universal-agent.git
git push -u origin main
```

**Никогда** не кладите токены и ключи в файлы репозитория и в файлы задач —
ключи живут только в переменных окружения (`UA_LLM_API_KEY`, деплой-секреты).
Утёкший в текст/чат ключ считается скомпрометированным: отзыв немедленно.
