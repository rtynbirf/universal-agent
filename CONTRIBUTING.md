# Contributing

Язык проекта: документация — русский, коммиты и код — английский/русский вперемешку по примеру окружающих файлов.

## Коммиты

1. **Conventional Commits**: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:` (+ scope: `feat(memory): ...`).
2. **DCO**: каждый коммит несёт `Signed-off-by` — `git commit -s`. Подпись означает согласие с [DCO](https://developercertificate.org/).
3. Никаких секретов в diff: токены живут в переменных окружения (`UA_*`), гигиену проверяет `scripts/check.py`.

## Верификация (канон)

Перед каждым пушем:

```bash
make verify        # = python3 scripts/check.py
# Result: N passed, 0 failed (of N checks) — иначе пуша нет
```

`check.py` прогоняет: компиляцию всех модулей, unittest-набор, скан на секреты, сходимость SHA-256-манифеста, комплектность release-файлов.

## Pull Request (канон POLIMAT)

- Заголовок PR = сообщение коммита (CI проверяет semantic-pull-request).
- Тело по шаблону `.github/PULL_REQUEST_TEMPLATE.md`: Summary / Type / Breaking changes / Verification / Checklist.
- PR живёт не дольше 24 часов и мержится squash-ом; `Signed-off-by` дублируется в итоговое сообщение.
- Патчи готовятся веткой `feat/...`; повторный пуш того же содержимого не дублируется (идемпотентность по содержимому).

## Архитектура

Существенные изменения архитектуры (новый контур памяти, смена протокола действий, песочница) описываются в PR Summary с мотивацией и сравнением альтернатив. Мозг сменяем, тело наследуемо: изменения `LLMCore` не должны ломать слои 1–4.
